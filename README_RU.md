# IT.MEET (IT.МИТ) — Платформа поиска тиммейтов IT.МОСКВА

Мобильное Android-приложение для студентов образовательной экосистемы **IT.МОСКВА**, помогающее находить участников в команды для хакатонов, учебных, дипломных и пет-проектов.

---

## Основной функционал

* **Регистрация и вход:** создание студенческой анкеты с привязкой к учебной группе и email `@it.moscow`. После регистрации карточка автоматически появляется в общей ленте поиска.
* **Умный поиск кандидатов:** просмотр профилей студентов с указанием роли, стека технологий, «суперсилы» и сетевого статуса («В сети» / был в сети).
* **Система взаимных откликов:** при нажатии лайка (`✓`) пользователю отправляется входящий отклик. Общий чат создаётся только в том случае, если второй участник нажмёт **«Ответить»** (при нажатии **«Отказать»** чат не создаётся).
* **Живые командные чаты:** двусторонние диалоги между участниками команды без ботов и автоответов.
* **Личный профиль:** редактирование информации о себе и загрузка аватара из галереи устройства.
* **Модерация и безопасность:** отправка жалоб из чата с подробным комментарием о нарушении, а также панель администратора (`admin@it.moscow`) для блокировки доступа, удаления анкет и обработки жалоб.

## Технологический стек

* **Язык:** Kotlin
* **UI-фреймворк:** Jetpack Compose (Material Design 3)
* **Загрузка изображений:** Coil (`io.coil-kt:coil-compose:2.7.0`)
* **Минимальная версия Android:** Android 8.0 (API 26)
* **Среда разработки:** Android Studio (Kotlin DSL / Gradle)
