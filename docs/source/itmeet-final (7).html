Политика конфиденциальности и Правила сообщества IT.МИТ

1. Назначение платформы: сервис «IT.МИТ» создан для студентов колледжа IT.МОСКВА с целью формирования команд для хакатонов, курсовых, дипломных и пет-проектов.

2. Персональные данные: указывая имя, учебную группу и стек навыков, пользователь соглашается на отображение анкеты другим студентам внутри образовательной экосистемы.

3. Правила общения: запрещены оскорбления, спам и публикация сторонней рекламы. Нарушители блокируются по кнопке «Жалоба».
